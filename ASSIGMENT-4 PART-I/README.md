## 1. Assignment Overview

This assignment focuses on designing, analysing and verifying algorithms using structured pseudocode.

The main objective is to develop clear algorithmic solutions by identifying inputs, outputs, conditions, decision-making processes, termination conditions and dependencies.

The assignment explores greedy algorithms, dynamic programming and graph algorithms through practical problem-solving scenarios.

## 4. Pseudocode Conventions

The assignment follows SIMATS-style pseudocode conventions.

- ALGORITHM
- INPUT
- OUTPUT
- BEGIN and END
- IF, THEN, ELSE
- FOR and WHILE
- Assignment operator (←)
- Comments using //
- SORT
- EXTRACT_MIN

These conventions make the algorithms language-independent and easier to implement.

## 1. Assignment Overview

This assignment focuses on understanding and implementing Divide and Conquer algorithms.

The main objective is to analyse how complex problems can be divided into smaller subproblems, solved independently and combined to obtain the final result.

The assignment includes theoretical analysis, algorithm implementation, experimental validation, comparison of execution times and complexity analysis.
